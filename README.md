# Viso - 智能交互式视频清理助手 🎥

`Viso` 是一个专为整理庞大视频库设计的高性能命令行工具。它不仅能通过元数据识别垃圾视频，更引入了 **视觉指纹** 和 **音频频谱** 双通道比对技术，能够跨分辨率、跨格式揪出重复内容。

## 🌟 核心特性

*   **视觉+音频双通道比对**：32x32 感知哈希（pHash）视觉指纹 + 音频频谱指纹，双通道交叉验证，准确率更高。
*   **智能截取片段识别**：滑动窗口时序对齐，即使片段从视频中段截取也能识别。
*   **广告容忍**：音频比对使用滑动窗口，即使视频中插入广告也能匹配。
*   **分组展示**：扫描结果按类型分组（文件重复/压缩副本/截取片段/时长过短/分辨率过低），一目了然。
*   **极致安全**：镜像回收站结构，下载中文件保护（5分钟活跃保护），支持跨盘秒级移动。

## 🧹 清理规则详解

`Viso` 内置了一套多维度的逻辑引擎，扫描时会自动应用以下规则：

### 1. 重复检测 (`duplicate`)

#### 物理指纹
对文件头、中、尾采样计算 MD5。文件大小和采样哈希一致则视为完全重复。

#### 视觉指纹 (pHash)
均匀提取 N 个时间点的 32x32 灰度缩略图，转换为二值化感知哈希（pHash）。使用 XOR bit-count 计算汉明距离，对亮度/对比度变化免疫。

#### 音频频谱指纹
每 10 秒提取一段 32x32 音频频谱图，转换为感知哈希。使用滑动窗口匹配，容忍广告插入导致的中断。

#### 检测类型
*   **异质重复**（优先级 90）：视觉+音频指纹高度相似且时长一致（误差 < 3s），即视为同一视频的不同分辨率/格式版本。
*   **截取片段**（优先级 85）：视觉指纹序列通过滑动窗口时序对齐匹配，且片段显著短于原片（差异 > 5s），即视为截取片段。

#### 匹配阈值
*   采样点命中率 ≥ 60%
*   感知哈希汉明距离 < 100（1024 bit 中约 10% 差异）
*   音频匹配通过滑动窗口容忍广告插入

#### 原件判定
发现重复时，按 **分辨率 > 码率 > 修改时间 > 路径长度** 自动选出最优原件保留，仅清理冗余副本。

### 2. 时长过滤 (`duration`)
*   识别总时长短于阈值的视频（默认 **5s**，通过 `-d` 自定义）。

### 3. 低分辨率过滤 (`resolution`)
*   识别画面过小的视频（默认 **< 480x320**，通过 `-W`, `-H` 自定义）。

## 🛡️ 安全保护逻辑 (自动生效)

为了防止误删，工具默认开启以下保护：
*   **活跃文件排除**：最后修改时间在 **5 分钟内** 的文件自动跳过（防止正在下载/录制）。
*   **临时文件跳过**：自动屏蔽 `.crdownload`, `.part`, `.tmp`, `.aria2`, `.xltd` 等临时后缀。
*   **回收站隔离**：自动跳过所有 `.viso-trash` 文件夹及其子目录。

## 🚀 快速开始

### 1. 安装依赖与编译
需要安装：
- **Go 1.25+**
- **FFmpeg**（需包含 `ffprobe` 与 `ffmpeg`）

```bash
go mod tidy
go build -o viso ./cmd/viso/main.go
```

### 2. 命令列表

| 子命令 | 说明 | 示例 |
|--------|------|------|
| `scan` | 扫描目录中的视频并输出检测报告 | `./viso scan ~/Videos` |

### 3. 扫描参数

| 参数 | 短参数 | 默认值 | 说明 |
|------|--------|--------|------|
| `--samples` | `-s` | `5` | 视觉指纹采样点数量。增加可提升截取片段检测精度，建议 6~10 |
| `--duration` | `-d` | `5s` | 最小保留时长，低于此值的视频会被标记 |
| `--width` | `-W` | `480` | 最小宽度阈值 |
| `--height` | `-H` | `320` | 最小高度阈值 |

### 4. 使用示例

```bash
# 基本扫描
./viso scan ~/Videos

# 高精度扫描（8 个采样点，最小时长 10 秒）
./viso scan ~/Videos -s 8 -d 10s

# 自定义分辨率阈值
./viso scan ~/Videos -W 640 -H 360
```

### 5. 构建验证
```bash
go test ./...
./viso scan .
```

## 📂 回收站机制
文件永远不会被直接物理删除。它们被移动到扫描根目录下的 `.viso-trash` 文件夹中，并镜像了原有的目录层级。
**彻底删除**：确认无误后，手动执行 `rm -rf .viso-trash`。
